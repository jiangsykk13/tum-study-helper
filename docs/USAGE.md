# 使用说明

安装见 [INSTALL.md](INSTALL.md)（手动）或 [AI_INSTALL.md](AI_INSTALL.md)（让 Claude Code / Codex 代为安装）。下面的命令都在项目文件夹里的 PowerShell 中运行；`<学习根目录>` 指放 `课程对照表.md` 和 `Planner\` 的文件夹（默认是项目的上一层，例如 `D:\TUM`）。

这是你个人使用的 Moodle 小助理。连接后，你可以直接向 AI 提问，让它查看你自己的课程、资料、成绩和作业状态，也能把课程文件整理到电脑上。它需要你的账号本来就有权限查看这些内容。

它也能读取 **Artemis**（artemis.tum.de）上的课程、讲座课件、练习，以及课程公告和交流频道。

它不会交作业、发帖，也不会修改 Moodle 或 Artemis 上的任何设置。

## 可以怎么问

| 功能 | 能做什么 | 向 AI 提问的例子 |
|---|---|---|
| 列课程（`list_courses`） | 查看进行中、过去、未来或全部课程。 | “列出我当前的 Moodle 课程。” |
| 看课程结构（`list_activities`） | 按原来的顺序列出章节、文件、作业和文字说明。 | “看看机器学习课程里有哪些资料和说明。” |
| 找文件（`list_files`） | 找出某个资料或文件夹页面里的可下载文件。 | “这个课程文件夹里有哪些文件？” |
| 读页面（`read_page`） | 阅读说明、论坛或课程页，保留表格、标题和列表。 | “读一下这份作业要求，把表格也展示出来。” |
| 下载（`download`） | 将指定资料下载到你选择的位置，同名文件会另取名字。 | “把这份讲义下载到 D:\TUM\资料。” |
| 查截止日期（`upcoming_deadlines`） | 查看接下来一段时间内 Moodle 显示的待办期限。 | “未来两周有哪些事情快到期了？” |
| 查成绩（`grades`） | 查看 Moodle 上各门课的评分项和反馈（例如加分测验、练习得分）。正式成绩在 TUMonline，不在这里。 | “查看我的课程总成绩。”或“看看机器学习这门课的评分明细。” |
| 查作业状态（`assignments`） | 查看开放时间、截止时间、最晚接收时间、提交与评分状态。 | “机器学习课程的作业交了吗？有没有分数和反馈？” |
| 同步整门课（`sync_course`） | 预览或保存课程文件，只处理新增和有变化的资料。 | “预览把机器学习资料同步到 D:\TUM\资料\机器学习，会有哪些变化？” |
| Artemis 课程（`artemis_courses`） | 列出你在 Artemis 上的课程。 | “我在 Artemis 上有哪些课？” |
| Artemis 课件（`artemis_lectures`） | 按时间列出某门 Artemis 课的讲座和课件。 | “Artemis 上那门课有哪些讲义？” |
| Artemis 练习（`artemis_exercises`） | 按截止时间列出某门 Artemis 课的练习（编程题、测验等）：是否已开放、截止时间、是否计分、你的得分。 | “FoP 这周有哪些 Artemis 练习要交？” |
| Artemis 频道（`artemis_channels`） | 列出课程公告和讨论频道，显示哪些可以读取。 | “FoP 的 Artemis 上有哪些公告和讨论区？” |
| Artemis 帖子（`artemis_posts`） | 分页读取指定频道的帖子、作者身份、时间和可见回复，也能搜索。保留原来的未读状态。 | “读一下 FoP 的 announcement 频道，看看监督练习怎么安排。” |
| 下载 Artemis 课件（`artemis_download`） | 下载一份 Artemis 课件，同名文件会另取名字。 | “把 Artemis 上第 2 讲的讲义下载到 D:\TUM\资料。” |
| 同步 Artemis 课程（`artemis_sync`） | 和上面的同步一样：先预览，确认后再下载，旧版本保留。 | “预览把 Artemis 那门课的课件同步到 D:\TUM\资料\某课-Artemis。” |

课程可以用名称的一部分、课程简称或编号指定。Moodle 和 Artemis 的课程编号互不相通：问 Artemis 的课时，说明“Artemis 上的”。如果名称对应多门课，AI 会需要更明确的课程信息。文字说明在课程列表里可能只有简短预览，可以再让 AI 读取完整课程页。

## 不用 AI：本机网页界面

双击桌面上的 **TUM 学习小助理**（开始菜单里也有，可以搜索）。不会出现黑色终端；页面在你平时用的 Chrome 里新开一个标签页，和其他网页放在一起（没装 Chrome 时用默认浏览器）。

- **常驻后台**（可选）：创建快捷方式时加 `--resident`，登录 Windows 时就自动在后台启动（开始菜单“启动”文件夹里有一个同名快捷方式，
  不开标签页），关掉标签页也不退出。不想让它开机启动，删掉 `shell:startup` 里那个快捷方式即可；要停止它，在任务管理器里结束 `pythonw.exe`。
- **在 Mac（或 iPad）上用**（可选，需要 [Tailscale](https://tailscale.com)）：两台设备登录同一个 Tailscale 账号，在 Windows 上运行一次
  `tailscale serve --bg --http=80 http://127.0.0.1:47823`（重启后仍有效；关掉用 `tailscale serve --http=80 off`），
  创建快捷方式时加 `--resident --tailscale`，然后在 Mac 浏览器打开 `http://<Windows 电脑名>.<你的 tailnet>.ts.net/`
  （在 Tailscale 管理页面能看到，建议加书签）。不需要令牌：Tailscale 会告诉小助理是谁在访问，只放行你自己的账号；
  别人的设备、公网都进不来。数据、文件和同步都在 Windows 上，Mac 上点“打开文件夹”不起作用。这个地址是 HTTP（Tailscale 内部本来就加密），
  浏览器不会给它发系统通知的权限，番茄钟结束时只有提示音。如果 47823 端口被别的程序占了，小助理会换端口，Mac 就连不上（`ui.log` 里会写）。
- 程序更新后会自动重启并刷新页面。
- 已经开着时再点一次图标，会再开一个小助理标签页，不会重复启动。
- Chrome 的“节省内存”功能有时会让长时间没看的标签页休眠，小助理会因此退出；回到那个标签页时会提示，重新点一次图标即可。
- 启动不了时会弹出提示框说明原因；详细记录在 `%LOCALAPPDATA%\TUM-Study-Helper\ui.log`（不含密码和登录信息）。
- 快捷方式被删了，或项目换了位置，在项目目录运行一次下面的命令就能重新创建（需要常驻后台或 Tailscale 时在后面加 `--resident`、`--tailscale`）：

```powershell
.\.venv\Scripts\python.exe -I .\tum_moodle_auto.py install-shortcut
```

想看到后台输出（排查问题时），也可以照旧双击项目里的 `moodle-ui.bat`：它会开一个黑色窗口，在平常的浏览器里打开页面，关掉黑色窗口才退出。

页面有七部分，左下角可以切换浅色、深色模式（默认跟着电脑的设置）：

- **今日计划**（打开就是这一页）：每晚 23:30 自动生成的第二天学习计划（需要先按 [nightly-plan/README.md](nightly-plan/README.md) 设好每晚任务）。每项任务可以选“完成 / 一半 / 没做”，随时能改；
  欠下的任务还可以选“不再补”。前一天没做完的任务也会列出来，晚上 23:30 以后做完的可以第二天补勾。这一页只读本机的
  `<学习根目录>\Planner` 文件夹，不需要登录，打开很快。每晚的自动任务设好之前，这里会显示“还没有计划”。
  第一次使用时有一份“开学盘点”，列出开学以来每门课的所有内容，每项选“完成 / 不够好 / 没做”；没做和不够好的会排进之后的计划去补。
  课程任务按课程分组：当天安排在前，“顺延待补”和已经完成的任务默认折叠，全部任务仍然保留。展开状态在当前浏览会话中记住，打勾和保存反馈后不会全部收起。
  页面先显示查看日期和生成状态，再显示一周日期条；完整月历通过“展开月历”查看，里面也能打开“开学盘点”。今天没有正式计划时会明确提示正在展示哪一天的旧计划。
  提醒先显示两条，其余按需展开；今天有正式计划时，“建议先做”提供最多三项任务的跳转和专注入口。过期事项单独收起，不再显示为“今天”。
  顶部区分当天安排、按打勾估算的完成量、按原项去重的累计待补、实际记录的专注时间。补旧任务另外计量，不抬高当天安排的完成比例。
  资料旁可打开所在文件夹；旧 Java 题也保留练习入口，并区分最近检测时未作答、作答后零通过和没有可靠检测记录。打开页面不会编译代码。
  “生成详情”显示最后更新时间和完成阶段；超过一小时没有更新时提示“可能中断”。已有草稿不会在打开页面时自动发布。
- **番茄钟**：专注、短休息、长休息（每 4 个番茄一次）和正计时（最长 3 小时）。专注时长在计时圈上方选：25、35、45 分钟、1 小时，
  或“自定义…”（1–180 分钟）；选过的时长会记住，下次默认用它。开始前在右边选“专注于”什么：
  今天计划里的任务，或者只选课程；计划页每项任务旁的“专注这项”会直接带过来，计划页上也会显示这项已经专注了多久。
  计时在本机记着：刷新页面、切到别的页面、关掉标签页甚至电脑睡眠都不会丢，回来时按真实时间补上（中途结束的番茄会记在它真正结束的时刻）。
  左侧“番茄钟”旁边和浏览器标签上会显示剩余时间。结束时有提示音和系统通知（第一次会问是否允许通知），休息可以自动开始。
  “提前结束”会保留已专注的时间（满 1 分钟才记），但不算完成的番茄，可以顺便选个中断原因；“放弃”则不记录。
  “全屏专注”只留下计时圈；在这一页按空格键也能开始或暂停。时长、每日目标、自动开始、提示音和通知在“设置”里改。
- **专注统计**：“概览”按日、周、月、年或自定义日期看专注时间、完成的番茄和完成率、日均（按有专注的日子平均）、最长一次、
  每天（或每小时、每月）的柱状图、一天中的专注时段、各课程和各任务用了多少时间、中断原因，以及最近一年的日历热力图和连续天数。
  点柱子或热力图的格子可以看那一天的记录。“记录”里可以按日期、课程、关键词查每一条，修改课程/任务/备注，删除，
  给忘了计时的学习“补录”（标为补录，不算番茄，不能和已有记录重叠），以及导出备份、导入备份（只添加新记录）。
  所有数据存在 `<学习根目录>\Planner\专注记录.json`，不需要联网。
- **截止日期**：接下来 7、30 或 90 天要处理的事项，48 小时内到期的标红。
- **课程**：每门课的章节、文件、说明文字；点“文件”可下载，点“阅读”在右侧打开页面。课程里还有“作业”，以及（对照表里填了 Artemis 编号时）“Artemis 课件”。对照表“状态”一列写了“已完成”的课（例如已考完的集中授课）放在“已结束”里，不在“进行中”。
- **成绩**：Moodle 上各门课的总成绩，只有一页，没有明细。正式成绩请在 TUMonline 查。
- **同步中心**：读取 `<学习根目录>\课程对照表.md`，把每门课 Moodle 和 Artemis 上的资料合在一起，同步到该课的 `Official` 文件夹。先点“预览选中”看会有哪些变化，再点“同步选中…”并确认，才会真正下载。目标文件夹可以在表格里改。

单个文件下载默认放进该课的 `_Inbox` 文件夹（没有对照的课放进 `<学习根目录>\_Inbox`），下载前可以改。

几点说明：

- 页面只在这台电脑上运行，别的网站访问不到；开了 `--tailscale` 时，别的设备只有经 Tailscale、用你自己的账号才能访问。本机每次启动的地址都不同，旧标签页会提示“没有访问权限”，用新打开的那个即可。
- 第一次读取时会先自动登录 TUM，需要等十几秒。
- 用完直接关掉窗口（用 `moodle-ui.bat` 打开时关掉黑色窗口）；登录状态随之清除。网页界面和 AI 使用的是同一套功能和安全规则。
- 网页、AI和每晚任务同步同一个目录时，程序会提示目录正在使用；稍后重试即可。

## 在 ChatGPT 网页版里用（只读）

ChatGPT 网页版运行在 OpenAI 的服务器上，没法直接启动你电脑上的程序。这里用 OpenAI 官方的 **Secure MCP Tunnel**（安全隧道）：你电脑上运行一个 OpenAI 的小程序 `tunnel-client`，它主动连到 OpenAI，ChatGPT 的请求顺着这条连接送过来。你的电脑不开放任何端口，也没有公开网址。

ChatGPT 只能用 12 个**查看**功能：课程列表、课程内容、文件列表、读页面、截止日期、成绩、作业，以及 Artemis 课程、讲座、练习、频道和帖子。**下载和同步不开放**，ChatGPT 不能往你的电脑写任何文件。

### 准备（只做一次）

1. 登录 [OpenAI Platform](https://platform.openai.com)，在 [Tunnels 页面](https://platform.openai.com/settings/organization/tunnels) 创建一个隧道，记下它的编号（`tunnel_` 开头），并把它关联到你的 ChatGPT 工作区。
2. 在 [API keys 页面](https://platform.openai.com/settings/organization/api-keys) 新建一个密钥，权限只给这个隧道的 Tunnels **Read** 和 **Use**。
3. 从 Tunnels 页面或 [GitHub 发布页](https://github.com/openai/tunnel-client/releases/latest) 下载 `tunnel-client-<版本>-windows-amd64.zip`，解压出 `tunnel-client.exe`，放到 `%LOCALAPPDATA%\tunnel-client\tunnel-client.exe`（在资源管理器地址栏输入 `%LOCALAPPDATA%` 即可打开该目录，没有 `tunnel-client` 文件夹就新建一个）。
4. 在 PowerShell 里运行下面的命令，按提示输入隧道编号和密钥。密钥输入时不显示，会存进 Windows 凭据管理器，不写进任何文件：

   ```powershell
   .\.venv\Scripts\python.exe -I .\tum_moodle_auto.py setup-chatgpt
   ```

5. 先双击 `chatgpt-bridge.bat`（见下文），再到 ChatGPT 添加自定义 MCP 服务器：名称随意（如“TUM Moodle”），「连接」选 **隧道**，选中刚才的隧道。小助理自己不需要额外的登录；「身份验证」如果有“无”就选它。

### 每次使用

- 想在 ChatGPT 里查时，双击 `chatgpt-bridge.bat`，会出现一个黑色窗口。窗口开着，ChatGPT 就能查；**关掉窗口就断开**，ChatGPT 再也连不到。
- 用完就关。平时不开，就没有任何连接。
- 同一时间只开一个这样的窗口。

几点说明：

- 你问的课程内容、成绩和反馈会经过 OpenAI 的服务器，交给 ChatGPT 处理。
- 网址里带 `sesskey`（Moodle 用来确认操作的口令）的请求会被直接拒绝，返回结果里的 `sesskey` 也会被遮住，所以即使 ChatGPT 被网页内容误导，也无法借小助理在 Moodle 上做任何改动。
- 这条连接还**没有用真实账号试过**；如果添加或连接失败，把 ChatGPT 的提示和黑色窗口里的文字（先确认里面没有密钥）告诉 AI 帮你排查。

## 第一次设置

见 [INSTALL.md](INSTALL.md)：存账号（`setup`）、检查登录（`test`、`test-artemis`）、连接 AI、写课程对照表。

每次小助理重新启动后，第一次用到 Artemis 时会登录一次。Artemis 可能为此给你发一封“有新登录”的邮件，这是正常的；不想收可以在 Artemis 的通知设置里关掉。

## 改了 TUM 密码怎么办

重新运行上面的 `setup`，输入相同 TUM ID 和新密码，然后重新连接小助理。不要在聊天里发送新密码。TOTP 项留空会保留之前存储的密钥；换了验证器密钥时，重新填写新密钥。

如果登录被拒绝，小助理会停止，不会不断尝试。先检查账号、密码和两步验证是否正确。

## 同步资料：先预览，再下载

每门课选择一个独立目录。先对 AI 说：

> 预览把机器学习这门课的文件同步到 D:\TUM\资料\机器学习。只预览，不下载。

默认就是预览（`dry_run=true`）：会显示新增、更新、未变化、线上已删除和失败的文件数量与名单，不创建目录，也不改动文件。

看过结果后，如果要实际保存，再说：

> 按这个目录实际同步机器学习资料，请用 dry_run=false 下载。

文件按类型放进 `Slides`（课件、讲义）、`Exercises`（练习和答案）、`Exams`（考试）、`Other`（其他）四个文件夹，不再照搬 Moodle 上的章节和文件夹层级；同一门课 Moodle 和 Artemis 的文件放在一起，文件名保持 Moodle 上的原名。类型按名称里的关键词自动判断，放错了告诉 AI 调整即可。再次同步时，本地和线上保持一致（2026-11-15 起）：新增文件会下载；有变化的文件换成新版，旧版移到 Windows 回收站；老师在线上删掉的文件也移到回收站。需要时都能从回收站恢复，不会被直接删除。你自己改过的文件（比如在 PDF 上做了批注）不会丢：线上也更新时，你的那份改名为 `名字 (批注).pdf` 留在原处，新版放在原名；线上删掉时，你的那份留着不动。原来就在目录里的同名文件不会被覆盖，新文件会加 ` (1)` 等后缀。

Analysis（数学分析）老师上传的文件名很乱（比如第 2 次习题是 `LA_Sheets (31).pdf`），所以这门课的文件按 Moodle 上的活动名命名，如 `Sheet 2.pdf`、`2026 analysis chapter 5.pdf`；已经下载的文件在下次同步时自动改成新名字。

Entrepreneurship 是单独配置的例外：Lecture（122369）和 Exercise（122367）仍共用四类目录，文件名前加 `Lecture S02 - ` 或 `Exercise S02 - `，Session 从章节名称读取。习题课课件和模板归 `Exercises`，阅读论文归 `Other` 并以 `Reading - ` 开头。确认相同的重复论文共用一个文件，保留各自来源；某个来源后来更新成不同内容时会分开保存。其他课程沿用原规则。

本地整理命令默认只预览：`python -I -B planner.py materials reorganize --course MGTHN0133`；加 `--apply` 才实际整理。执行前完整备份该课 Official 和材料索引到 `<学习根目录>\Planner\备份\Entrepreneurship_<时间>\`，旧位置的文件移入备份，不丢弃重复副本。整理中断时，重新执行带 `--apply` 的命令或实际同步会先恢复；不要手动删除 `.entrepreneurship-reorganize.json`。重复执行没有变化时不会再备份。旧计划通过材料编号和版本显示新位置，正式计划与完成记录不改写。

**小助理不会彻底删除本地课程文件**：线上换掉或删掉的旧版只移到 Windows 回收站，你改过的文件保留。下载中断时可能留下 `.part` 文件，原文件保留，下一次可以重试。

Artemis 课程的同步方法相同，文件也放进同样的四个类型文件夹，和这门课的 Moodle 资料放在一起，文件名是“讲座名 - 附件名”。老师在 Artemis 上重新上传同名课件时，只保留最新版，旧版本移到回收站。

目录里以 `.moodle-sync-` 和 `.artemis-sync-` 开头的文件（后面是课程编号）是同步记录，记录资料链接、更新时间、保存位置和文件内容摘要，不包含登录凭据。请保留它，也不要手动修改；记录损坏时小助理会停止并说明原因。出现 `.journal.json` 表示上次文件交接尚未结束，再次同步会先恢复，不能手工删除。旧版同步记录会在下一次实际同步时升级，预览不改记录。

同步现在也会检查课程页面、文字说明里的站内附件，并保存可读取的页面和标签文字。结果会说明哪些项目尚未开放、类型暂不支持、链接在站外或读取失败；没有报错不再等同于所有内容都已收齐。老师在站外放的视频或资料仍不会自动抓取。

文件内容有摘要可供核对。本地文件被修改时会单独提示并保留；站点只改了更新时间、文件内容相同时，不会当作更新。下载中断后的恢复记录能避免再次下载出无意义的同名副本。预览遇到更新时间变化会保守估计为“更新”，实际下载后内容相同则显示“未变”。

## 学习计划与反馈

设好每晚任务后（见 [nightly-plan/README.md](nightly-plan/README.md)），计划由 Claude 或 Codex 每晚 23:30 生成，网页打开和打勾不需要联网。夜间任务先确定柏林日期、恢复上次阶段，再写草稿；只有检查通过才发布正式计划。错过夜间任务、白天补跑而今天还没有计划时，会先补今天。重复运行同一个目标日会复用计划和Java练习。

- **欠账不会因为重新安排而减少。** 原任务90分钟，今天只安排其中50分钟：没做仍欠90，完成这次安排后欠40，一半则欠65。重复安排同一部分不重复抵扣；旧日期可以补勾和撤销。
- **“不再补”放弃整个原任务的剩余部分**，包括其他日期安排的同一项；可以恢复。
- **可选学习反馈**：展开任务卡中的“学习反馈”，填写实际分钟数与“理解／吃力／没懂”。不填也能正常使用，用时不会直接替代完成状态。
- 欠账、周进度与科研时长会随着打勾立即更新。已经在其他日期完成的内容会有提示，不必重复学习。
- 下载成功但尚未解读的材料会留在清单中；超过每晚读取上限的页码继续留待下次处理。任务可以列出具体材料版本和页码。
- Java结果显示最近检测的测试结果和时间。只有新的代码作答才影响下一道同类题难度，不会因连续几晚重测同一份答案不断升级。

程序仍使用 `<学习根目录>\Planner\规划设定.md` 里的学习时间、课程比例和特殊日期。日历仍用于了解刚上过哪些课，没有增加按空闲时段排程。数据操作和命令详见 [nightly-plan/每晚任务说明.md](nightly-plan/每晚任务说明.md)。

## 目前的限制

- 作业解析按 Moodle 4.x 的通常页面设计，**未经真实 TUM 作业页面验证**。不认识的状态会显示“未知”并附原始文字，不能据此认定未提交。
- 成绩仅显示 Moodle 已提供的内容；**正式成绩在 TUMonline**，小助理的程序不读取 TUMonline。尚未发布的分数无法读取。成绩功能已用真实页面验证过（2026-10-12），但当时出分的课程很少，遇到复杂的成绩表时仍建议和网页对照一下。
- 截止日期列表来自 Moodle 的待办事件，可能不包含全部考试、日程或已经完成的任务。
- 同步只涵盖你可访问的资料和课程文件夹，暂不抓取论坛附件等其他活动中的所有文件。实际下载使用 Windows；过长、过深的路径可能需要换一个更短的保存目录。
- 有可靠版本标记的资源仍优先依赖网站更新时间和文件标记；网站同时更换内容却保留全部标记时，仍可能无法立即发现。没有任何验证标记的文件会读取内容比较；本地文件修改也会被检查。
- 登录页改版、未知的两步验证或额外授权页面可能需要后续适配。长时间同步中登录过期时，部分文件可能失败，需要重新调用后重试。
- Artemis 支持课件、练习列表和课程频道的公告、帖子及可见回复；不读取私信或群聊，不自动加入频道，不展开转发原帖；帖子和回复里的附件（PDF、图片）会列出链接（`attachments`），可以用 `artemis_download` 下载，也不读取练习的提交内容。帖子默认每页20条、最新在前，可用 `page`、`page_size` 和 `search` 翻页或搜索；`has_more` / `next_page` 表示还有下一页，不能把单页当作全部历史。练习只能看，不能提交。课件没有“文件标记”，只能靠链接和更新时间判断变化；课件被改名时会当作“旧的线上删除、新的新增”。
- 合并表格会近似展开，最多处理 256 列；复杂排版请以 Moodle 原页面为准。

## 隐私和安全

账号、密码和验证密钥只存 Windows 凭据管理器。登录后的临时会话只保留在运行中的内存里，关闭服务后失效，不写入同步记录或日志；错误信息会隐藏会话信息。

访问范围仅限 TUM Moodle、完成登录所需的两个 TUM 登录站点，以及 Artemis（artemis.tum.de）。网页里出现的其他网站下载链接会被拒绝。只有在你打开 `chatgpt-bridge.bat` 时，OpenAI 的 `tunnel-client` 才会连到 OpenAI（api.openai.com），关掉窗口即断开。

AI 会看到你让它查询的课程内容、成绩和反馈；下载的资料、旧版本及同步记录也会留在你指定的电脑目录，请按个人资料保管。不要将包含个人信息的查询结果、同步记录或下载目录随意公开。

课程说明和论坛内容只是资料，小助理不会执行其中的指令。所有网站操作保持只读。
