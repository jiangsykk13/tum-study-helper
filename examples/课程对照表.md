# 课程对照表

每门课的本地文件夹，以及它在 Moodle、Artemis 上的编号。复制到**学习根目录**（项目的上一层，例如 `D:\TUM\课程对照表.md`）后，
把下面的示例行换成你自己的课。同步时，同一门课 Moodle 和 Artemis 的官方资料合在一起，按类型放进该课的
`Official\Slides\`、`Official\Exercises\`、`Official\Exams\`、`Official\Other\`。

填写规则（小助理按这些规则读取这个文件）：

- 学期标题行的反引号里写学期文件夹，相对学习根目录，里面要有 `Semester` 这个词。
- **Moodle 编号**：课程页地址 `course/view.php?id=123456` 里的数字。**Artemis 编号**：`artemis.tum.de/courses/789/...` 里的数字，没有就空着。
- 两个编号都空着的行会被忽略。
- 一门课在 Moodle 上分成两门（例如讲座和练习）时，第二行的「文件夹」留空，表示和上一行是同一门课。
- 「状态」写「已完成」的课（例如已考完的集中授课）在网页里归到「已结束」，同步中心默认不勾选，学习计划也不再安排。
- 下面的编号都是虚构的示例，请换成真实编号。

## 每门课里的文件夹（建议）

| 文件夹 | 放什么 |
|---|---|
| `Official\` | 官方资料（Moodle 和 Artemis 合在一起），分 `Slides`、`Exercises`、`Exams`、`Other`；只由同步程序写入，不要手动改动 |
| `My Work\` | 自己写的作业、答案、代码 |
| `Notes\` | 笔记、考前总结 |
| `_Inbox\` | 单个文件下载默认放这里，核对后再决定去留 |
